## 🎯 LA PROPOSITION

### Problème
```
Africa: 500M+ éleveurs, ZÉRO accès télémédecine vétérinaire

Réalité:
  • Distances: 50-200 km au plus proche vétérinaire
  • Coût: Déplacement = 20-50% du profit visite
  • Temps: Perte 2-5 jours productifs (animal malade)
  • Résultat: Mortalité animale 30-40% vs 5-10% monde développé
```

### Solution: MokineVeto
```
App mobile (iOS/Android) connectant:
  ✓ Éleveurs (50 000 - 500 000) 
    → consultation vétérinaire en < 2 minutes
    → prédiagnostic IA + ordonnances numériques
    → marketplace vétérinaire intégrée

  ✓ Vétérinaires (500 - 5 000)
    → demandes de consultation automatisées
    → suivi patients (animaux) numérisé
    → paiements fiables (Mobile Money)

  ✓ Vendeurs/Agrovet (100 - 1 000)
    → marketplace intégrée
    → accès éleveurs directs
    → commissions plateforme
```
